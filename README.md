# Air Quality Analysis

Automated air quality dashboard: a daily GitHub Action will pull Open-Meteo data for the 5 largest US cities. A [marimo](https://marimo.io/) analysis notebook, hosted on GitHub Pages, will run entirely in the browser, allowing visualization and data exploration by visitors to the site.

> This repo is a work in progress. Under construction, not yet deployed. See the [project notes](docs/PROJECT_NOTES.md) for details.
